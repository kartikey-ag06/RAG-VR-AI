Users & document permissions (RBAC)

Off while there are no users: everyone sees every document. After the first user exists, a document tagged with groups on the upload page is visible only to users in those groups (admins see all). Create an admin first.

Connectors

Send reports to a webhook / email / Jira / ServiceNow, or keep a folder (e.g. a synced SharePoint or Google Drive folder) indexed automatically.

MCP endpoint (for other AI assistants)

Tools: list_documents, search_documents, get_page, ask_documents. Set the MCP_TOKEN environment variable on the server to allow access from other computers.
